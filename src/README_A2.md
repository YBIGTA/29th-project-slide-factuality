## 이 논문에서 실제로 터진 것들

### 1. 마침표가 문장 끝이 아닌 자리

`segment.py` 의 `_PROTECT` 에 정규식으로 넣어뒀다. 길이를 보존하며 마스킹하므로
kiwi 가 주는 오프셋을 원문에 그대로 쓸 수 있다.

| 패턴 | 실제 사례 |
| --- | --- |
| 쪽수 | `pp.682-683`, `p.679` |
| 권호 | `Vol.44, No.4` |
| 라틴 약어 | `Op. cit.`, `et al.`, `Ph.D` |
| 이니셜 | `J. Glasser` |
| 소수점 | `4.3배` |
| 날짜 | `1995.12.6.` |

### 2. 문장 끝에 공백이 없다

`수행했다.이러한 이중적인` — 조판 과정에서 공백이 사라진다.
`. ` (마침표+공백)으로 자르는 방식은 여기서 무너진다. kiwi 는 이걸 알아서 처리한다.

### 3. 절 제목이 각주 번호와 똑같이 생겼다

```
1) 간전기의 역설: 산업적 주도권과 민족주의의 이중주      <- 본문 절 제목
13) Christopher Silver, "Listening to the Past", ...    <- 각주
```

둘 다 `N)` 으로 시작하고 **둘 다 페이지 하단에 올 수 있다.**
번호만 보고 각주로 잘라내면 **본문 문단이 통째로 사라진다.** (실제로 두 문단을 잃었다)

→ 해결: 본문에 달려 있던 각주 마커 번호를 먼저 수집하고(`8~21`),
그 번호로 시작하는 줄만 각주로 인정한다. 절 제목의 `1)` `2)` 는 마커 집합에 없으므로 살아남는다.

### 4. 문장이 페이지를 넘어간다

1쪽 끝 `아랍 고전 음악을 대중적` + 2쪽 시작 `인 영역으로 끌어내는` = `대중적인 영역으로`

→ 페이지 경계를 그냥 이어붙인다. **머리말/각주를 먼저 지운 뒤에** 이어야 한다.

### 5. `․` 는 마침표가 아니다

`종교적․전통적` 의 `․` 는 U+2024 ONE DOT LEADER다. 마침표처럼 보이지만 다른 글자다.
가운뎃점 `·` 로 정규화한다. 반대로 이걸 `.` 으로 바꾸면 문장이 거기서 잘린다.

### 6. 각주 마커가 문장 중간에 박힌다

`묘사11)했으나` — 문장 끝이 아니라 어절 중간이다. `지적한다.8)` 은 마침표 뒤다.
`(?<=[가-힣.’”\)])\d{1,2}\)` 로 지운다. 연도 `(1904)` 는 4자리라 걸리지 않는다.

## PDF 추출에서 주의할 것

**`extract_text()` 기본 모드는 한글 공백을 전부 잃는다.**
`extraction_mode="layout"` 을 써야 한다. 라틴 문자도 기본 모드에서는
`M oham ed Sfindja` 로 깨지는데 layout 모드에서는 `Mohamed Sfindja` 로 정상이다.

대신 layout 모드는 **줄바꿈이 단어를 쪼갠다.** `작동했`+`다.`, `가장 소`+`중히`.
`LineJoiner` 가 형태소 태그로 판단한다.

1. 오른쪽이 어미·조사로 시작 → **붙인다** (`보여준`+`다.`, `메`+`웠으며`)
2. 왼쪽이 조사·어미·문장부호로 끝남 → **띄운다** (`문법을`+`통해`)
3. 왼쪽이 체언 → 분석 점수가 높은 쪽

> `kiwi.space()` 를 문서 전체에 돌리면 안 된다.
> `안달루시아`→`안달 루시아`, `20세기`→`20 세기` 로 멀쩡한 곳이 망가진다.
> 공백이 아예 없는 8자 이상 덩어리에만 적용하고, 고친 내역은 전부 로그로 남긴다.

**자동 정제는 완벽하지 않다.** 이 논문에서도 `안달 루시아`, `폐쇄적 인사제`,
`열 린`, `학술적자 산으로` 가 남았다. `.review.txt` 를 보고 손으로 고친 뒤
라벨링에 넘긴다.

## find_evidence() — 이게 A-2의 핵심이다

라벨 시트의 `evidence_text`(원문 복붙)를 구간에 붙인다.
**이게 없으면 B-1이 recall 을 계산할 수 없다.**

```python
from segment import split_sentences, build_spans, find_evidence

sents = split_sentences(open("docs/clean/arts_01.txt", encoding="utf-8").read())
w3 = build_spans(sents, window=3)

m = find_evidence(sents, w3, "실제로 1929년 한 해에만 그라모폰사의 아랍어 음반 판매량이 20만 장에 달하며")
m.sent_ids   # ['s052']
m.span_ids   # ['w3_050', 'w3_051', 'w3_052']   <- 정답 구간 집합
m.method     # 'exact'
```

복붙이 완벽하지 않을 것을 전제하고 3단계로 느슨해진다.

| method | 언제 | 검증됨 |
| --- | --- | --- |
| `exact` | 정규화 후 그대로 포함 | 원문 복붙 · 일부만 복붙 · 따옴표 종류 다름 · 각주 마커 딸림 |
| `nospace` | 공백 다 지우고 포함 | 띄어쓰기 틀림 · 조사 사이 공백 |
| `fuzzy` | 유사도 0.85 이상 | 글자 몇 개 다름 |
| `none` | 못 찾음 | **버리지 말고 사람이 고친다** |

가이드에서 근거 2개를 ` || ` 로 나눠 적게 한 것도 처리한다.

### 정답이 여러 개인 게 정상이다

윈도우 stride 가 1이라 한 문장은 **w3에서 3개, w5에서 5개** 구간에 들어간다.
정답은 단일 구간이 아니라 **집합**이다. top-k 안에 이 중 하나라도 있으면 hit.

→ B-1에 넘길 때 이 점을 명확히 할 것. 정답을 하나로 잡으면 recall 이 실제보다 낮게 나온다.
