# 어노테이션 가이드라인 v2.0 (guideline_v2.md)

PPT 슬라이드 팩트체크는 일반 줄글 문서와 다릅니다. 함축성, 요약성, 파편화된 텍스트를 다루기 위해 다음의 v2.0 가이드를 전원 즉시 적용합니다.

## 📌 핵심 원칙 (Golden Rule)
1. **Closed-book 평가**: 어노테이터의 개인 지식이나 외부 검색은 절대 금지합니다. 오직 주어진 참조 텍스트(Reference) 안에 명시된 정보만으로 판단합니다.
2. **의미적 동치 허용**: 토씨가 달라도 문맥상 같은 의미로 요약/종합된 문장이면 '근거 있음'으로 인정합니다. (기계적 단어 찾기 금지)
3. **PPT 특수성 인정**: 슬라이드의 목차, 단어 나열, 고유명사 등은 단순한 '글자'가 아니라 "이 발표에서 다룰 유의미한 사실적 대상"이라는 암묵적 Claim으로 간주합니다.

## 🏷️ 4대 라벨 적용 기준 및 예외 처리 가이드

### 1. 근거 있음 (Supported)
- **정의**: 슬라이드의 Claim이 참조 텍스트에 명시되어 있거나, 텍스트의 내용을 논리적 비약 없이 요약/종합한 경우.
- **적용 기준 (PPT 특화)**:
  - **고유명사/연도/명사구**: 슬라이드에 "에드몽 야필", "1961" 처럼 단어만 덜렁 기재되어 있어도, 해당 키워드가 참조 문헌 내에서 중요한 인물/사건/소제목으로 다뤄지고 있다면 '근거 있음'입니다. (Benign 남용 방지)
  - **요약 및 패러프레이징**: 텍스트의 여러 문장을 합쳐 "이중적 지위의 전략"과 같이 요약한 경우, 문맥상 일치하면 '근거 있음'입니다. (무근거 남용 방지)

### 2. 무근거 (Unsupported)
- **정의**: 슬라이드의 Claim 내용(혹은 추가된 구체적 디테일)이 참조 텍스트에서 전혀 확인되지 않는 경우.
- **적용 기준**:
  - **과도한 구체화 (매우 중요)**: 텍스트는 포괄적으로 서술했는데, 슬라이드는 구체적으로 적은 경우 무조건 '무근거'입니다. (예: 텍스트 "비극적 파멸" ➔ 슬라이드 "암살" = 무근거 / 텍스트에 없는 "콩스탕틴" 지명 등장 = 무근거)
  - **외부 지식 엄금**: 역사적 사실이 맞더라도, 주어진 텍스트 지면에 안 적혀 있으면 '무근거' 처리합니다.

### 3. 모순 (Contradicts)
- **정의**: 슬라이드의 Claim이 참조 텍스트의 사실, 데이터, 혹은 '저자의 핵심 주장'과 정면으로 충돌하는 경우.
- **적용 기준**:
  - **비판적 맥락의 왜곡**: 저자가 A라는 현상("조화로운 공생")을 비판하거나 부정하기 위해 언급했는데, 슬라이드에서는 A를 '사실'인 것처럼 단정지어 적어놓았다면 '모순'입니다.
  - 수치, 인과관계, 선후관계가 원문과 반대인 경우.

### 4. Benign (검증 불필요 / 사실적 주장 아님)
- **정의**: 팩트체크의 대상이 될 수 없는 순수 장식성 텍스트, 인사말, 주관적 감상.
- **적용 기준 (Strict)**:
  - "감사합니다", "Q&A", "목차", "오늘의 발표 주제" 같은 슬라이드 운영용 텍스트에만 제한적으로 사용합니다.
  - **예외 (Benign 불가)**: 역사적 사건명, 인물 이름, 연도, 이론명, 본문 소제목을 따온 짧은 구(Phrase)는 절대 Benign으로 처리할 수 없으며, 반드시 텍스트 내 존재 여부를 확인해 [근거 있음/무근거/모순] 중 하나로 판별해야 합니다.
